## 서비스 개요

- 서비스명: Purity
- 성격: 전환율 최적화(CRO) 패널 서베이 SaaS MVP
- 목적: 기업이 자사 랜딩페이지/콘텐츠/가격 등을 실제 타겟 패널에게 검증받고,
         정량적 피드백(5개 축 점수)을 통해 마케팅 자산을 개선하도록 지원
- 사용자 역할: 3종 (company / panel / admin)

================================================================

5. 소재 A/B 비교 (/company/preference) — PreferenceTest.jsx  ★ 전면 재설계

   - Step 1: 소재 A/B 입력 + 이미지 업로드 (선택, 각 1장)
     · variantA / variantB 텍스트 필수 — 둘 중 하나라도 비어있으면 다음 단계 불가
     · 이미지는 선택 사항 (텍스트만 입력해도 다음 진행 가능)
     · 업로드 경로: {companyId}/{missionUuid}/va.{ext} / vb.{ext}
     · 미리보기 썸네일 + 삭제 지원
   - Step 2: 제품/타겟 설명 입력 (패널에게 표시됨, productDescription)
   - Step 3: 패널 수 & 예상 비용 + 질문 설정
     · 기본 A/B 선호도 질문만 사용 (radio card)
     · DB 템플릿 카드 선택 → 질문 번호 카드 목록으로 표시
     · 커스텀 질문 추가 (최대 3개, × 삭제 버튼)
   - 등록 시: missions INSERT(type='preference', description=JSON.stringify({
       variantA, variantB, variantAImage, variantBImage,
       productDescription, customQuestions})) + preference_tests INSERT
   - 제출 후 missionUuid 리셋 (중복 제출 방지)
   - 결과 화면: A/B 선택 비율 바 + message_clarity / purchase_intent 평균 표시

## 역할 2: Panel (패널/응답자)
================================================================

인증 후 /panel 하위 라우트 접근 가능.

1. 대시보드 (/panel) — Dashboard.jsx  ★ 개편
   - 신뢰도 게이지 (trust_score %)
   - 미션 현황 (3칸 묶음): 완료 미션(총 누적) / 참여 가능(슬롯 여유 있는 active 미션) / 이번 주 활동(7일 내 제출)
     · 참여 가능 수: status='active' + 슬롯 여유(filled_count < panel_count) + 미참여 미션 전수 조회 (limit 없음)
   - 수익 현황 (3칸 묶음): 총 정산 완료(금액+건수) / 정산 대기 중(금액+건수) / 필터 탈락(건수)
     · feedbacks(status≠draft) SELECT → purity_passed/status 기준 집계
   - 참여 가능한 미션 카드 목록 제거 (→ 미션 탐색 페이지로 유도)

2. 미션 탐색 (/panel/missions) — Missions.jsx
   - 탭 3개: 참여가능 / 진행 중(→/panel/active로 이동) / 완료
   - 참여가능: missions status='active' + 미참여(feedbackMap에 없음) + 슬롯 여유 있는 것
   - 완료: 패널이 submitted/approved/rejected 상태인 피드백이 있는 미션
   - 참여가능·완료 탭: 메인 의뢰(LP검증) / 서브 의뢰(소재비교·가격검증·이메일검증) 섹션 분리 ★ 개편
   - 각 섹션 10개씩 페이지네이션 (PanelMissionCard 컴포넌트 분리, 수락/취소 모달 유지) ★ 개편
   - 수락 확인 모달: Purit Filter 경고 3항목 포함 (ReactDOM.createPortal 기반, viewport 중앙 고정)
   - 수락 시 feedbacks INSERT(status='draft', 점수는 null) → /panel/active?id=... 이동
   - 수락 취소 모달: ConfirmModal 컴포넌트 사용, cancel_panel_feedback RPC 호출
   - Dashboard의 참여가능 목록에서는 draft 포함 모든 참여 미션 제외

3. 미션 수행 (/panel/active) — ActiveMission.jsx
   ★ 목록 뷰 (id 파라미터 없음, /panel/active):
     - 이 패널이 수락한(status='draft') 미션을 메인 미션 / 서브 미션 섹션으로 분리 표시 ★ 개편
     - 각 카드에 미션 유형 배지 표시 (소재 비교/가격 검증/이메일 검증)
     - 저장된 진행 없으면 "피드백 시작하기 →", 있으면 "이어하기 →" 버튼
     - 버튼 클릭 시 /panel/active?id=<mission_id>로 이동
   ★ 폼 뷰 (id 파라미터 있음, /panel/active?id=...):
     - 특정 미션 브리핑 화면 → mission.type에 따라 3가지 폼 분기
     - 브리핑에서도 저장 여부에 따라 "이어하기 →" / "피드백 시작하기 →"
     - 브리핑 description 표시 ★ 개편:
       · 서브 미션: parseSubDesc 파싱 → productDescription(제품/타겟 설명) 표시
       · 메인 미션: mission.description 원문 표시
       · raw JSON이 그대로 노출되는 버그 수정
     ※ 서브 미션 폼 (type='preference'|'pricing'|'email', isSubMission=true):
       - parseSubDesc(desc, type) 헬퍼로 하위 호환 JSON 파싱 (구 포맷 raw text 자동 감지)
       - preference: productDescription 표시, variantAImage/variantBImage 이미지 표시,
                     variantA/B 텍스트 → A/B 선택 + message_clarity + purchase_intent + comment
       - pricing: parsedDesc.image 이미지 표시, parsedDesc.content 설명 표시,
                  productDescription 섹션, price_fairness + value_perception + would_buy + comment
       - email: parsedDesc.content 원문 표시, productDescription 섹션,
                open_intent + hook_score + clarity_score + curiosity_score + would_reply + comment
       - 제출: preference_responses/pricing_responses/email_responses INSERT + feedbacks UPDATE(submitted) + RPC 2개
     ※ 이미지 미션 (image_urls 있음, isSubMission=false):
       - ImageAnnotator 컴포넌트로 이미지 위에 드래그 영역 지정
       - 어노테이션 추가: 팝업에서 dimension(5종) + score(1-5) 선택 → 확인
       - 같은 dimension을 여러 번 드래그 가능 → 명1, 명2, 명3 / 가1, 가2 등 번호 자동 부여
         (short 코드: 명확성=명, 관련성=관, 가치=가, 차별화=차, 신뢰=신)
       - 이미지 아래 dimension별 번호 코멘트 박스 표시 → 각 박스에 textarea로 코멘트 입력
       - 코멘트는 1초 debounce → feedback_annotations.comment 컬럼 실시간 UPDATE
       - feedback_annotations 테이블에 실시간 저장/삭제
       - 제출 시 dimension별 평균점수 → clarity_score 등 컬럼에 반영
         suggestions = 어노테이션 요약 텍스트 통합
     ※ 텍스트 미션 (image_urls 없음, 하위 호환):
       - "이어하기" 클릭 시 점수가 비어있는 첫 번째 단계로 직접 이동 (resume)
       - 중복 제출 방지: 동일 mission+panel 조합 사전 체크
       - 5개 축 점수(1-5) 입력
       - 각 축 텍스트 코멘트 → [레이블]\n코멘트 형식으로 suggestions 하나에 통합 저장
         (strengths는 draft 중 JSON 임시 저장에 사용, 제출 시 null로 초기화)
       - 자동 저장: 점수/코멘트 변경 후 1.5초 debounce → feedbacks UPDATE
     - 수락 취소 버튼(draft 상태일 때) → cancel_panel_feedback RPC → /panel/missions 이동
     - 제출 시:
       a. feedbacks UPDATE (status: draft → submitted, strengths: null, suggestions 통합)
       b. missions.filled_count +1 → RPC increment_mission_filled_count (SECURITY DEFINER)
       c. panels.total_missions +1 → RPC increment_panel_mission_count (SECURITY DEFINER)

4. 수익 이력 (/panel/history) — History.jsx  ★ 개편
