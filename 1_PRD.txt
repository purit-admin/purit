## 서비스 개요

- 서비스명: Purity
- 성격: 전환율 최적화(CRO) 패널 서베이 SaaS MVP
- 목적: 기업이 자사 랜딩페이지/콘텐츠/가격 등을 실제 타겟 패널에게 검증받고,
         정량적 피드백(5개 축 점수)을 통해 마케팅 자산을 개선하도록 지원
- 사용자 역할: 3종 (company / panel / admin)

1. 대시보드 (/company) — Dashboard.jsx
   - NDA 배너 최상단 표시: "Purit의 피드백 패널은 기업의 정보를 발설할 수 없습니다."

   - 차트 섹션: 가로 3열 그리드 (equal-height stretch), 각 카드 동일 높이 자동 맞춤 ★ 개편
     · 1열 — 5차원 레이더 차트: feedbacks 실데이터 집계 → 내 점수 vs 플랫폼 벤치마크 비교
     · 2열 — KPI 달성률 게이지: 5축 평균을 100점 환산한 반원형 RadialBarChart + 5축 미니 바
     · 3열 — 패널별 긍/부정 반응 분포 ★ 개편
       - 메인 의뢰 섹션: feedbacks 5개 score 컬럼 평균 ≥3.5 → 긍정 비율 수평 바

       - 서브 의뢰 섹션: 타입별 응답 테이블 점수 평균 ≥3.5 → 긍정 비율 수평 바
         computeSubSentiment(missions, prefResps, priceResps, emailResps):
           preference → message_clarity + purchase_intent 평균
           pricing    → price_fairness + value_perception 평균
           email      → open_intent + hook_score + clarity_score + curiosity_score 평균
       - 메인/서브 각 섹션 4개씩 캐러셀 (‹ › 화살표 버튼, 5개 이상 시만 표시)
       - 상태 변수: mainSentPage / subSentPage / prefResps / priceResps / emailResps
       - 피드백 없는 의뢰: '—' 표시 (hasData=false)
   - 전체 의뢰 현황 (통합 섹션): ★ 개편
     · "진행 중인 의뢰" 별도 섹션 제거 → "전체 의뢰 현황"에 통합
     · 탭 5개: 전체 / 진행 / 완료 / 임시 저장 / 취소 — 기본 선택: "진행" (missionFilter='active') ★

     · CompanyMissionCard 뱃지: LP검증 뱃지 미표시, 서브 의뢰(소재비교/가격검증/이메일검증)만 타입 뱃지 표시 ★
       뱃지 색상: 소재비교=blue(진한회색) / 가격검증=gold / 이메일검증=blue(진한회색) ★ 이메일 green→blue 변경
     · CompanyMissionCard 상태 뱃지: active+filled=0 → "매칭 대기"(gray), active+filled≥1 → "진행 중"(green), completed → "완료"(blue) ★
     · CompanyMissionCard: 카드 클릭 시 navigate('/company/results?id=<missionId>') → Results.jsx가 해당 의뢰 즉시 선택
     · CompanyMissionCard: status='active' && filled_count=0 조건 시 "수정" 버튼 표시
       클릭 시 DRAFT_ROUTE 맵으로 타입별 올바른 폼 경로로 navigate (메인→/company/new, 서브→각 서브 페이지)
     · CompanyMissionCard: status='active' && filled_count≥1 조건 시 "의뢰 조기 종료" 버튼 표시
       클릭 시 ConfirmModal(danger) → status='cancelled' UPDATE
       모달 경고 문구: "⚠️ 조기 종료 시 잔여 크레딧은 환불되지 않습니다. 이미 수집된 피드백 결과는 계속 확인 가능합니다."

     · CompanyMissionCard: status='draft' 카드 클릭 시 DRAFT_ROUTE 맵으로 해당 폼으로 이동
       (landing_page→/company/new, preference→/company/preference, pricing→/company/pricing-test, email→/company/email-test)
       draft 카드 우측 상단에 "이어 작성하기 →" 버튼, 우측 하단에 "삭제" 버튼 표시, 카드 테두리 dashed amber
     · CompanyMissionCard: status='completed' 카드 우측 하단에 "삭제" 버튼 표시
       클릭 시 ConfirmModal(danger) 확인 → missions DELETE + 카드 즉시 제거 (복구 불가)
