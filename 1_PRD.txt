## 서비스 개요

- 서비스명: Purity
- 성격: 전환율 최적화(CRO) 패널 서베이 SaaS MVP
- 목적: 기업이 자사 랜딩페이지/콘텐츠/가격 등을 실제 타겟 패널에게 검증받고,
         정량적 피드백(5개 축 점수)을 통해 마케팅 자산을 개선하도록 지원
- 사용자 역할: 3종 (company / panel / admin)

================================================================

인증 후 /company 하위 라우트 접근 가능.

1. 대시보드 (/company) — Dashboard.jsx

   - 5차원 레이더 차트: feedbacks 실데이터 집계 → 내 점수 vs 플랫폼 벤치마크 비교
     (피드백 미수집 시 0점 표시, 수집 시 자동 반영)
   - KPI 달성률 게이지: 5축 평균을 100점 환산한 반원형 RadialBarChart
   - 긍/부정 스택 바 차트: 의뢰별 평균점수 ≥3.5 → 긍정 비율 수평 바 (최대 5개 의뢰)
   - 전체 의뢰 현황 (통합 섹션): ★ 개편
     · "진행 중인 의뢰" 별도 섹션 제거 → "전체 의뢰 현황"에 통합
     · 탭 4개: 전체 / 진행 / 완료 / 취소 (어드민 미션관리와 동일 구조)

     · CompanyMissionCard: status='active' && filled_count=0 조건 시 "수정" 버튼 표시
       클릭 시 navigate('/company/new', { state: { editMode: true, missionId } }) 이동
   - Framer Motion 애니메이션: 섹션 fadeUp / Stats staggerChildren
   ※ 차트 데이터 소스: feedbacks 테이블(status='submitted') 실시간 집계

2. 의뢰 등록/수정 (/company/new) — NewMission.jsx

     · 기존 title/lpUrl/description/panels/focusAreas/imageUrls/persona 자동 복원

     · Step 3 검토 화면에 ⚠️ "첫 피드백 수신 후 수정 불가" 경고 표시
     · 제출 버튼: 신규="의뢰 제출 →" / 편집="수정 완료 →"
   - Step 0 기본 정보 (패널에게 공개되지 않는 내부 관리용 정보):
     · 제품명, LP URL 입력
     · 예상 소요 시간 선택 UI 제거됨 (DB 저장은 기본값 5분 유지)
     · 난이도 필드 제거됨
   - Step 1 타겟 페르소나: 산업군, 직책, 경력 + '타겟 상세(선택)' 자유 입력
   - Step 2 소재 업로드: 이미지 업로드 (최대 5장, 5MB) + 검증 포인트(FOCUS) 선택
     · FOCUS 항목: 첫인상/가독성, CTA 전환율, 가격 및 가치 전달, 신뢰 요소,
                   모바일 최적화, 핵심 메시지 명확성, 비주얼 완성도, 타겟 일치도
     · 패널 수 선택 → 보상금 산출 + Pro 플랜 20% 할인 안내
     · 업로드 경로: {company_id}/{missionUuid}/{uuid}.{ext}
     · missions.image_urls TEXT[] 컬럼에 public URL 배열 저장
   - Step 3 검토: 난이도 행 없음, '의뢰 제출 →' 버튼
   - 제출 시 Supabase missions 테이블에 INSERT (id 사전 생성 UUID), status='active'

3. 피드백 결과 (/company/results) — Results.jsx  ★ 전면 재설계 완료 (2026-04-30)
   - 레이아웃: 좌측 230px 패널(미션 선택) + 우측 콘텐츠 2열 구조
   - 좌측 패널: 메인 의뢰 / 서브 의뢰 섹션 분리, 타입 뱃지 + 피드백 수 표시
   - 우측 콘텐츠: mission.type 및 image_urls 유무에 따라 3가지 분기
     A. 이미지 미션 (image_urls 존재 && !isSubMission):
        · 6개 탭: [명확성][관련성][가치][차별화][신뢰][종합]
        · 차원 탭: ImageAnnotator(readonly)로 전체 패널 어노테이션 오버레이 + 코멘트 목록
        · 종합 탭: 5차원 평균 점수 카드 + RadarChart + 패널 총평 목록
          - 총평 파싱: extractOverallComment() → feedbacks.suggestions의 [총평]\n 이후 텍스트
        · feedback_annotations: eq('mission_id') 전체 로드 → 클라이언트에서 dimension 필터
     B. 서브 미션 (type: preference/pricing/email):
        · preference: A/B 선택 비율 바 + message_clarity/purchase_intent 평균 카드 + 코멘트
        · pricing: would_buy 비율 바 + price_fairness/value_perception 평균 카드 + 코멘트
        · email: would_reply 비율 바 + open_intent/hook_score/clarity_score/curiosity_score 카드 + 코멘트
        · 각 타입 공통: CustomQuestionsSection 추가 (코멘트 목록 아래)  ★ 신규
          - parsedDesc.templateQuestions + 정규화된 customQuestions → 질문별 응답 집계
          - radio: 옵션별 응답 수 + 비율 바, scale: 평균 점수 카드, text: 답변 목록
          - custom_answers가 없는 레거시 응답은 자동 제외 (데이터 있는 경우만 렌더)
        · 각 타입 응답 테이블 쿼리: select('*') → custom_answers JSONB 자동 포함
     C. 텍스트 미션 (image_urls 없음 && !isSubMission): 기존 패널 목록+상세 뷰 유지
   - 공유 링크: 우측 미션 헤더 영역 배치 (missions.share_token 생성/복사/해제)
   - 패널 직군/경력 뱃지: 각 피드백 항목 옆에 패널의 직군(blue)·경력(gray) 뱃지 표시
     · 이름·전화번호 비공개 — get_panel_public_profiles RPC(SECURITY DEFINER) 경유
     · 표시 위치: 종합 탭 총평, 차원 탭 어노테이션, 텍스트 미션 패널 목록,
                  소재비교·가격검증·이메일검증 코멘트 항목
   - ※ panels 조인 없음 (RLS 차단 원칙 D-28 준수)

5. 소재 A/B 비교 (/company/preference) — PreferenceTest.jsx  ★ 질문 선택 UI 개편
   - 목록 빈 상태: 우측 상단 "+ 새 테스트" 버튼 없음 / 중앙 "+ 새 테스트" 버튼 하나만 표시
   - Step 0: 소재 유형 선택 (이미지/텍스트/랜딩페이지)
   - Step 1: 소재 A/B 입력 + 이미지 업로드 (선택, 각 1장)
     · variantA / variantB 텍스트 필수 — 둘 중 하나라도 비어있으면 다음 단계 불가
     · 이미지는 선택 사항 (텍스트만 입력해도 다음 진행 가능)
     · 업로드 경로: {companyId}/{missionUuid}/va.{ext} / vb.{ext}
     · 미리보기 썸네일 + 삭제 지원
   - Step 2: 제품/타겟 설명 입력 (패널에게 표시됨, productDescription)
   - Step 3: 패널 수 & 예상 비용 + 질문 설정  ★ 개편
     · 카테고리별 템플릿 3개 × 5문항 = 15개 질문을 아코디언 UI로 표시
       (QUESTION_TEMPLATES.preference에서 직접 로드 — DB 쿼리 없음)
     · 각 템플릿 헤더 클릭 시 해당 그룹 질문 목록 인라인 펼침/접힘
     · 질문 클릭 → 체크박스 선택/해제, 최대 5개 한도 (초과 시 나머지 회색 처리)
     · 우상단 "N/5 선택됨" 배지 실시간 표시
     · 커스텀 질문 추가 최대 3개 (서술형 고정, 5개 한도 내)
   - 등록 시: missions INSERT(type='preference', description=JSON.stringify({
       variantA, variantB, variantAImage, variantBImage,
       productDescription, selectedQuestions})) + preference_tests INSERT
     ※ selectedQuestions: [{id, text, type, options}] — 선택된 질문 스냅샷 (템플릿+커스텀 통합)
     ※ 구 포맷(templateQuestions + customQuestions) 레거시 미션은 패널/결과 화면에서 자동 폴백 처리
   - 제출 후 missionUuid 리셋 (중복 제출 방지)
   - 결과 화면: A/B 선택 비율 바 + message_clarity / purchase_intent 평균 + CustomQuestionsSection
