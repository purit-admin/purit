## [1] Results.jsx 전면 재설계
================================================================

대상 파일: src/pages/company/Results.jsx
우선순위: HIGH

### 현재 문제
- 미션 선택 UI가 칩 버튼 나열 방식 → 10개 이상 시 여러 줄로 펼쳐져 UX 저하
- 모든 미션 타입에 동일한 5축 점수 표시 → 서브 미션에 맞지 않는 지표 노출
- 이미지 미션 어노테이션 결과 미표시

### 재설계 목표

**미션 선택 UI**
- 좌측 패널 구조로 변경 (메인 의뢰 / 서브 의뢰 섹션 분리)
- 각 미션 카드에 타입 뱃지 표시

**미션 타입별 결과 분기**
- landing_page → feedbacks 5축 점수 (clarity/relevance/value/differentiation/trust)
  + 이미지 미션: 패널별 카드에 ImageAnnotator(readonly) + dimension별 코멘트 표시
  + 페이지 하단: 전체 집계 5차원 평균
- preference → preference_responses WHERE mission_id=selected
  · A/B 선택 비율 바 + message_clarity + purchase_intent 평균
- pricing → pricing_responses WHERE mission_id=selected
  · would_buy 비율 + price_fairness + value_perception 평균
- email → email_responses WHERE mission_id=selected
  · would_reply 비율 + open_intent + hook_score + clarity_score + curiosity_score 평균
