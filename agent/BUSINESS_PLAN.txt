## 비즈니스 전략
================================================================

[목표]
첫 기업 고객 유치를 위한 "맛보기 후 유료 전환" 모델 구현.
플랫폼 신뢰도 없는 초기 단계에서 가치를 먼저 증명하고 결제를 유도한다.

[제안 흐름]
1. 콜드 메일 발송 대상: thevc.kr / 스타트업 레시피 기준 최근 투자받은 시리즈 A 전후 스타트업
2. 제안 문구: "패널 10명이 준비되어 있습니다. 첫 의뢰는 무료로 진행해드립니다."
3. 의뢰 완료 후 → 프리뷰 모드로 결과 일부 공개 → 잠금 해제 유도

[패널 초기 수급 전략]
- 창업자 본인(마케팅 8년차 실무자) + 마케터 지인 3~4명으로 초기 패널 커버
- 어중이떠중이 패널보다 전문성 높은 피드백 제공 가능 → 품질 면에서 정당성 있음

## 프리뷰 모드 설계
================================================================

[공개 데이터 — 무료]
- 5개 지표 평균 점수 (명확성/관련성/가치/차별화/신뢰)
- 레이더 차트, KPI 게이지
- 이미지 위 어노테이션 박스 위치 (점, 영역 표시)
- 어노테이션 개수 카운트

[잠금 데이터 — 유료 해제]
- 어노테이션 텍스트 내용 (클릭 시 나오는 코멘트 팝업)
- 패널 텍스트 피드백 전문 (suggestions, strengths, weaknesses)
- 패널 총평 코멘트

[설계 근거]
점수를 보면 "왜 이 점수가 나왔지?"가 궁금해진다.
이유를 알고 싶어서 잠금을 해제한다.
점수조차 안 보이면 궁금증 자체가 생기지 않는다.
어노테이션 위치가 보이되 내용이 잠기면 FOMO가 극대화된다.

[잠금 해제 방식 — V1]
- 단건 결제: "이 미션 전체 결과 보기 — 50% 할인 (XX만원)"
- 구독 전환은 단건 결제 이후 "다음 의뢰부터는 구독이 더 저렴합니다"로 유도
- 즉각 구독 전환보다 단건이 첫 전환 장벽이 낮다

## 구현 범위
================================================================

[DB 변경 — Migration 1개]

ALTER TABLE missions
  ADD COLUMN is_preview BOOLEAN DEFAULT FALSE,
  ADD COLUMN preview_unlocked_at TIMESTAMPTZ,
  ADD COLUMN preview_price NUMERIC(10,2);

- is_preview: 이 미션이 프리뷰 모드인지 여부
- preview_unlocked_at: 결제 확인 후 어드민이 세팅 → NULL이면 잠금, 값 있으면 해제
- preview_price: 잠금 해제 단가 (미션별로 다르게 설정 가능)

[변경 파일 목록]

1. src/pages/company/Results.jsx
   - isPreviewLocked = mission.is_preview && !mission.preview_unlocked_at 판단 로직 추가
   - 잠금 상태: 점수/차트는 그대로 렌더, 텍스트 피드백에 블러 오버레이 처리
   - "전체 결과 잠금 해제 — XX만원 (50% 할인)" 버튼 표시
   - 버튼 클릭 시: 계좌이체 안내 모달 → 결제 확인 후 어드민 연락 안내

2. src/components/ui/ImageAnnotator.jsx
   - isPreviewLocked prop 추가
   - 어노테이션 박스 위치는 표시 (readonly 모드 그대로)
   - 클릭 시 나오는 코멘트 팝업: isPreviewLocked=true면 미표시 또는 "🔒 잠금" 표시

3. src/pages/admin/Missions.jsx (또는 별도 어드민 액션)
   - 미션 카드에 "프리뷰 모드 설정" 토글 버튼 추가
   - "잠금 해제" 버튼 추가 → 클릭 시 preview_unlocked_at = now() UPDATE
   - 결제 확인은 어드민이 수동으로 처리 (V1 기준)

## 결제 처리 전략
================================================================

[V1 — 수동 처리]
결제 게이트웨이(Toss Payments 등) 연동 없이 운영한다.

흐름:
기업이 "잠금 해제" 버튼 클릭
→ 모달: 계좌번호 + 금액 안내 + 연락처
→ 기업이 이체 후 연락
→ 어드민이 확인 후 Missions.jsx에서 "잠금 해제" 버튼 클릭
→ preview_unlocked_at 세팅 → 기업 포털 즉시 해제

이유: 결제 게이트웨이 연동은 구현 범위가 3배 커진다.
     첫 수십 건은 수동으로도 충분히 운영 가능하다.

[V2 — 자동화]
고객이 일정 수 이상 확보된 후 Toss Payments / Portone(아임포트) 연동.
단건 결제 → 자동 preview_unlocked_at 세팅.
