## DB 스키마 (Supabase / PostgreSQL)
================================================================

※ 코드에서 역설계한 스키마. 실제 Supabase 대시보드와 교차 검증 필요.

### [auth.users] — Supabase 내장
  id              UUID  PK
  email           TEXT
  user_metadata   JSONB  { role: 'company'|'panel'|'admin', name: TEXT }

---

### [companies]
  id              UUID  PK
  user_id         UUID  FK → auth.users.id  (UNIQUE, 1:1)
  name            TEXT
  plan            TEXT  (플랜명, 예: free/pro 등)

---

### [panels]
  id              UUID  PK
  user_id         UUID  FK → auth.users.id  (UNIQUE, 1:1)
  name            TEXT
  industry        TEXT
  experience      TEXT  (경력 연차 등)
  bio             TEXT
  expertise       TEXT[]  (전문 분야 배열)
  bank_name       TEXT
  bank_account    TEXT
  bank_holder     TEXT
  total_missions  INT   DEFAULT 0

---

### [missions]
  id              UUID  PK
  company_id      UUID  FK → companies.id
  title           TEXT
  type            TEXT  (예: 'landing_page')
  target_url      TEXT  (LP URL)
  description     TEXT  (브리프)
  persona         JSONB (타겟 페르소나 설정값)
  panel_count     INT   (요청 패널 수)
  filled_count    INT   DEFAULT 0 (제출 완료 수)
  reward_amount   INT   (보상금, 원 단위)
  status          TEXT  ('active'|'completed'|'draft'|'in_review'|'cancelled')
  assets          TEXT[]  (검증 포인트 목록)
  created_at      TIMESTAMPTZ DEFAULT now()

---

### [feedbacks]
  id                    UUID  PK
  mission_id            UUID  FK → missions.id
  panel_id              UUID  FK → panels.id
  clarity_score         INT   (1–5, nullable — draft 중에는 null 허용)
  relevance_score       INT   (1–5, nullable)
  value_score           INT   (1–5, nullable)
  differentiation_score INT   (1–5, nullable)
  trust_score           INT   (1–5, nullable)
  strengths             TEXT  (draft 중 임시 저장용: JSON.stringify(comments), 제출 시 null)
  weaknesses            TEXT  (null 고정, 하위 호환용)
  suggestions           TEXT  ([레이블]\n코멘트 형식 5개 섹션 통합, 제출 시에만 기록)
  purity_passed         BOOL  DEFAULT false
  status                TEXT  ('draft'|'submitted'|'approved'|'rejected')
                               ※ draft: 수락 후 미완료 (패널이 수락하면 즉시 생성)
                               ※ CHECK 제약: feedbacks_status_check 로 4개 값 허용
  created_at            TIMESTAMPTZ DEFAULT now()

  ※ RLS: SELECT(인증된 전체), INSERT(패널), UPDATE(인증된 전체)
  ※ DELETE 정책 없음 → 수락 취소는 cancel_panel_feedback RPC(SECURITY DEFINER)로 처리

---

### [gmv_snapshots] — 어드민 월간 GMV 스냅샷
  id           UUID  PK
  month_label  TEXT  (예: '7월')
  year         INT
  month_num    INT
  gmv          NUMERIC
  panel_pay    NUMERIC
  margin       NUMERIC
  created_at   TIMESTAMPTZ

---

### [settlements] — 패널 정산 내역
  id             UUID  PK
  panel_id       UUID  FK → panels.id  (NULLABLE)
  panel_name     TEXT
  tier           TEXT
  missions_count INT
  amount         NUMERIC
  status         TEXT  ('pending'|'paid'|'rejected')
  due_date       DATE
  created_at     TIMESTAMPTZ

---

### [invoices] — 기업 청구서
  id            UUID  PK
  company_id    UUID  FK → companies.id  (NULLABLE)
  company_name  TEXT
  plan          TEXT
  amount        NUMERIC
  status        TEXT  ('pending'|'paid')
  invoice_date  DATE
  created_at    TIMESTAMPTZ

---

### [notifications] — 시스템 알림
  id          UUID  PK
  user_id     UUID  FK → auth.users.id  ON DELETE CASCADE
  type        TEXT  ('success'|'warning'|'info')
  icon        TEXT
  title       TEXT
  body        TEXT
  action_url  TEXT
  read        BOOL  DEFAULT false
  created_at  TIMESTAMPTZ
  INDEX: (user_id, read)

---

### [team_members] — 기업 팀원
  id          UUID  PK
  company_id  UUID  FK → companies.id  ON DELETE CASCADE
  name        TEXT
  email       TEXT
  role        TEXT  ('admin'|'member'|'viewer')
  status      TEXT  ('active'|'invited'|'inactive')
  joined_at   DATE
  created_at  TIMESTAMPTZ

---

### [question_templates] — 질문 템플릿
  id          UUID  PK
  company_id  UUID  FK → companies.id  (NULLABLE = 플랫폼 기본)
  name        TEXT
  icon        TEXT
  category    TEXT
  description TEXT
  use_count   INT   DEFAULT 0
  is_default  BOOL  DEFAULT false
  created_at  TIMESTAMPTZ

### [template_questions] — 템플릿 세부 문항
  id            UUID  PK
  template_id   UUID  FK → question_templates.id  ON DELETE CASCADE
  question_text TEXT
  question_order INT

---

### [preference_tests] — 소재 선호도 A/B 테스트
  id          UUID  PK
  company_id  UUID  FK → companies.id
  asset_type  TEXT
  variant_a   TEXT
  variant_b   TEXT
  panel_size  INT   DEFAULT 10
  status      TEXT  ('draft'|'active'|'completed')
  created_at  TIMESTAMPTZ

### [preference_responses] — 선호도 응답
  id          UUID  PK
  test_id     UUID  FK → preference_tests.id  ON DELETE CASCADE
  panel_id    UUID  FK → panels.id
  preference  TEXT  ('A'|'B')
  comment     TEXT
  created_at  TIMESTAMPTZ

---

### [brand_tracking_campaigns] / [brand_tracking_monthly] / [brand_perception_items]

### [ai_reports] — AI 리포트 결과
  id              UUID  PK
  mission_id      UUID  FK → missions.id
  company_id      UUID  FK → companies.id
  tldr            TEXT  (AI 생성 요약)
  priority_fixes  JSONB  [{area, issue, action, impact}]
  strengths       JSONB  [string]
  risk_flags      JSONB  [{level: 'high'|'mid', text}]
  overall_score   NUMERIC(3,2)
  panel_count     INT
  created_at      TIMESTAMPTZ DEFAULT now()

  ※ RLS: SELECT(본인 company or admin), INSERT(service role — Edge Function)

---

### 관계 요약

  companies    ←1:1→  auth.users   (companies.user_id)
  panels       ←1:1→  auth.users   (panels.user_id)
  missions     ←N:1→  companies    (missions.company_id)
  feedbacks    ←N:1→  missions     (feedbacks.mission_id)
  feedbacks    ←N:1→  panels       (feedbacks.panel_id)
  ai_reports   ←N:1→  missions     (ai_reports.mission_id)
  ai_reports   ←N:1→  companies    (ai_reports.company_id)
  notifications←N:1→  auth.users   (notifications.user_id)
  team_members ←N:1→  companies    (team_members.company_id)
  settlements  ←N:1→  panels       (settlements.panel_id, NULLABLE)
  invoices     ←N:1→  companies    (invoices.company_id, NULLABLE)

---

### SECURITY DEFINER RPC 함수 목록

  increment_mission_filled_count(mission_id UUID)
    → missions.filled_count +1 (패널이 직접 UPDATE 불가 → RPC 필수)

  increment_panel_mission_count(panel_id UUID)
    → panels.total_missions +1 (패널이 본인 panels 직접 UPDATE 불가 → RPC 필수)

  cancel_panel_feedback(p_mission_id UUID)
    → feedbacks DELETE (status='draft', 본인 panel) (DELETE RLS 없음 → RPC 필수)
    → 파일: supabase/migrations/004_cancel_feedback_rpc.sql

  Divider      — 구분선
  EmptyState   — 빈 상태 플레이스홀더 (icon, title, desc)
