## 반응형 CSS 유틸리티 클래스 (src/index.css)

  반응형 구현 방식: 인라인 React 스타일 시스템 유지 + CSS 클래스 !important 오버라이드
  (인라인 스타일이 CSS 클래스보다 specificity가 높으므로 반응형 오버라이드는 !important 필수)

  ### 기존 (미션 카드)
  .mc-row    — 미션 카드 내부 좌/우 2열 레이아웃 (640px 이하: 1열로 전환)
  .mc-right  — 미션 카드 우측 영역 (보상금·슬롯·버튼 묶음)
