## DB 스키마 (Supabase / PostgreSQL)
================================================================

※ 코드에서 역설계한 스키마. 실제 Supabase 대시보드와 교차 검증 필요.

### [auth.users] — Supabase 내장
  id              UUID  PK
  email           TEXT
  user_metadata   JSONB  { role: 'company'|'panel'|'admin', name: TEXT }

---

### [companies]
  id              UUID  PK
  user_id         UUID  FK → auth.users.id  (UNIQUE, 1:1)
  name            TEXT
  plan            TEXT  (플랜명, 예: free/pro 등)

---

### [panels]
  id              UUID  PK
  user_id         UUID  FK → auth.users.id  (UNIQUE, 1:1)
  name            TEXT
  industry        TEXT
  experience      TEXT  (경력 연차 등)
  bio             TEXT
  expertise       TEXT[]  (전문 분야 배열)
  bank_name       TEXT
  bank_account    TEXT
  bank_holder     TEXT
  total_missions  INT   DEFAULT 0

---

### [missions]
  id              UUID  PK
  company_id      UUID  FK → companies.id
  title           TEXT
  type            TEXT  (예: 'landing_page')
  target_url      TEXT  (LP URL)
  description     TEXT  (브리프)
  persona         JSONB (타겟 페르소나 설정값)
  panel_count     INT   (요청 패널 수)
  filled_count    INT   DEFAULT 0 (제출 완료 수)
  reward_amount   INT   (보상금, 원 단위)
  status          TEXT  ('active'|'completed'|'draft'|'in_review'|'cancelled')
  assets          TEXT[]  (검증 포인트 목록)
  created_at      TIMESTAMPTZ DEFAULT now()

---

### [feedbacks]
  id                    UUID  PK
  mission_id            UUID  FK → missions.id
  panel_id              UUID  FK → panels.id
  clarity_score         INT   (1–5)
  relevance_score       INT   (1–5)
  value_score           INT   (1–5)
  differentiation_score INT   (1–5)
  trust_score           INT   (1–5)
  strengths             TEXT
  weaknesses            TEXT
  suggestions           TEXT
  purity_passed         BOOL  DEFAULT false
  status                TEXT  ('submitted'|'approved'|'rejected')
  created_at            TIMESTAMPTZ DEFAULT now()

---

### 관계 요약

  companies    ←1:1→  auth.users   (companies.user_id)
  panels       ←1:1→  auth.users   (panels.user_id)
  missions     ←N:1→  companies    (missions.company_id)
  feedbacks    ←N:1→  missions     (feedbacks.mission_id)
  feedbacks    ←N:1→  panels       (feedbacks.panel_id)

## 공용 컴포넌트 (src/components/ui/index.jsx)
================================================================

재사용 시 이 컴포넌트들을 우선 사용할 것.

  Btn          — 버튼 (variant: primary|secondary|ghost|danger|outline, size: sm|md|lg)
  Card         — 카드 컨테이너 (클릭 가능, hover 효과)
  Stat         — 지표 표시 (label, value, sub, accent)
  ScoreBar     — 점수 바 (score, max=5, color)
  Badge        — 태그/뱃지 (type: gray|gold|green|red|blue)
  Divider      — 구분선
  EmptyState   — 빈 상태 플레이스홀더 (icon, title, desc)
