## [무료 체험 Freemium] 첫 의뢰 1회 무료 + 부분 언락 ★ 신규 (085/087)
================================================================

신규 기업은 plan='free_trial'로 시작 → 첫 메인 의뢰 1회를 크레딧 없이 등록(free_trial_used로 1회 제한).
결과는 패널 2명분만 무료 공개하고 나머지는 잠금 → 충전/구독으로 언락하는 구조.

### 자격 & 등록 (NewMission.jsx)
- freeTrialAvailable = (companyPlan==='free_trial' && !free_trial_used). 메인 의뢰만 대상(서브 제외).
- Dashboard(/company): 자격 보유 시 상단 배너 "🎁 첫 의뢰는 무료입니다" + "무료로 의뢰 등록하기 →"(/company/new 직행).
- 등록 폼: 상단 큰 무료 배너 + 패널 10명 고정(슬라이더 캡) + 경력 주니어·미들만(시니어·헤드 차단) + 안내문구.
- 크레딧 0이어도 제출 가능(부족 게이트 우회). 제출 확인 모달: "최초 1회 무료 / 10명 중 2명 공개 / 나머지 8명 잠금 / 충전·구독 후 해제".
- 등록 하단 푸터: 의뢰 운영비 대신 "예상 잠금 해제 비용 N~M크레딧"(잠긴 8명 × 선택 경력 1~2cr) 범위 표시 + "등록 시 차감 없음" 안내.
- create_free_trial_mission RPC로 원자적 active 전환(reserve 우회, 1계정1회 FOR UPDATE) → 어드민에 🔥 강한 알림.
- ★ 식별 뱃지: 무료 첫 의뢰는 기업 포털 Dashboard·NewMission 목록·Results 좌측에 '🎁 체험 의뢰' 뱃지 표시(어드민 🎁 체험과 동일 — is_free_trial).
- ★ 무료 기회 복구(093): 어드민이 체험 의뢰를 '취소'만 해도 free_trial_used=false 복구 → 기업이 무료 의뢰 재등록 가능(admin_set_trial_mission_status, 삭제까지 안 가도 됨).
    재개 시 재소진(true). 기업이 직접 '조기 종료'한 경우는 복구 안 함(farming 방지). (구: 삭제 시에만 복구 — 091/D-124 확장)

### 결과 부분 공개 (Results.jsx)
- trialLocked = is_free_trial && !trial_unlocked. 5축 점수(레이더·바)는 10명 전체 집계로 항상 공개.
- 공개 2명 결정: ★ 어드민이 지정한 mission.trial_public_panel_ids(089)가 있으면 그 2명, 없으면 자동(★094 호평=평균점수 상위 2명, panel_id ASC tiebreaker) 폴백. 나머지는 블러+🔒.
  · ★094 점수기반 자동 선별: 호평 2명을 공개하고 저점(치명적) 패널을 잠가 빈틈(궁금증) 유발. panelAvgScore = 5축 평균, 서버 unlock RPC ROW_NUMBER(avg_score DESC, panel_id ASC)와 1:1 정합(D-121/D-35).
  · ★ 잠금 해제된 코멘트/총평을 앞 페이지로 정렬(잠긴 건 뒷 페이지 → 궁금증 유발). 총평 패널 번호는 정렬 후 표시 순서대로 재부여.
  · 잠긴 각 총평 카드에 패널 경력별 크레딧 칩 표시(★ 메인 1.5배 적용 — 주니어 1.5·미들 3·시니어 4.5·헤드 6 = getCareerUnlockCredit, 090/095). (per-panel 칩은 정가 단위 — 배너 총액은 할인가)
  · ★094 잠긴쪽 티저(배너 상단): 잠긴 패널 점수로 "잠긴 N명 중 M명이 심각한 문제(1~2점)를 지적했습니다" 집계(클라 표시 전용, AI 미사용). weakestAxis(가장 약한 축)는 계산하되 배너 문구에는 미노출(정신없음 방지 — 사용자 피드백).
  · ★094 30% 첫 언락 할인: 결과 최초 열람(trial_results_seen_at)부터 48h 이내면 적용. 가격·할인을 우측 잠금 해제 버튼에 통합 — 버튼 안 2줄(① '첫 언락 30%↓' 뱃지 / ② 정가 취소선 → 할인가(정가×0.70)크레딧으로 잠금 해제). 카운트다운(⏳ HH시간 MM분 SS초)과 "크레딧이 부족합니다" 문구는 버튼 아래 표시. 최초 열람 시 touch_trial_results_seen RPC가 앵커 1회 세팅. 마감 후엔 정가 단일 라벨("전체 잠금 해제 (Ncr)").
  · 어노테이션은 잠긴 패널 comment를 ''로 치환해 ImageAnnotator 툴팁 누출 차단.
  · ★ 추가 질문 응답(CustomQuestionsSection): 질문 텍스트·응답 건수는 공개, 응답 내용만 블러+🔒(질문은 보이고 응답만 잠금).
  · ★ 텍스트 미션(이미지 없는 메인, TextMissionResults): 잠긴 패널 좌측목록 🔒+점수바 블러, 상세 5축 블러+언락 오버레이, 추가 질문 응답 잠금 — 이미지 미션과 동일하게 적용.
- 미언락 미션은 공유 UI 숨김(get_shared_mission도 서버에서 차단) — 페이월 우회 방지.
- 언락 = 충전/구독 후 unlock_free_trial_mission RPC → 잠긴 패널 경력 크레딧 합(메인 1.5배) 정가에 ★094 48h 이내면 30% 할인(ROUND(정가×0.70,2)) 적용해 차감(서버 권위, 094). 어드민 지정 공개 2건 제외하고 합산. 반환 { cost, original_cost, discount, new_balance }.
- ★ 보안(092→094): missions에 UPDATE RLS가 없어 결제/언락 컬럼(trial_unlocked·trial_public_panel_ids·credits_*·unlock_cost·is_free_trial·trial_results_seen_at)을 기업이 직접 UPDATE해 무료 언락·할인 영구화하는 구멍을 BEFORE UPDATE 트리거(current_user 가드)로 차단. 정상 변경은 SECURITY DEFINER RPC만 허용.
