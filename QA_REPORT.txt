## 🔴 CRITICAL (즉시 수정 필요 — 플로우 중단 또는 데이터 손상)
================================================================

[C-1] 어드민 미션 "취소" 버튼 — 확인 모달 없이 즉시 실행  ✅

[C-2] 반려 알림 메시지와 실제 UI 흐름 불일치 — 재작성 방법 없는 페이지로 유도
  위치: src/pages/admin/PurityFilter.jsx → src/pages/panel/History.jsx
  재현: 어드민이 피드백 반려 → 패널에게 알림 발송 → 패널이 알림 클릭 → /panel/history 이동
  현재: 정산 내역 페이지에 재작성 버튼 없음. 재작성은 [미션 관리 → 수정 필요] 탭에서만 가능.
  기대: actionUrl을 '/panel/missions'로 변경하거나, 정산 내역 지급 거절 탭에 "재작성하기 →" 버튼 추가

[C-3] OAuthCallback — 에러 발생 시 무한 로딩 화면
  위치: src/pages/OAuthCallback.jsx
  재현: Google 로그인 → OAuth 완료 → handleCallback() 내부에서 Supabase 에러 발생
  현재: try-catch 없음. 에러 시 "로그인 처리 중..." 화면에서 영구 멈춤.
  기대: try-catch 추가, 에러 시 "로그인에 실패했습니다 / 로그인 페이지로 돌아가기" 표시

[C-4] 패널 대시보드 load() — try-catch 없어 무한 로딩 가능
  위치: src/pages/panel/Dashboard.jsx
  재현: 패널 대시보드 진입 → Supabase 쿼리 에러 발생
  현재: load()에 try-catch 없음. 에러 시 setLoading(false) 미호출 → 영구 로딩.
  기대: try-catch 감싸기 + 모든 exit path에 setLoading(false) 추가 (D-51 패턴)

[M-2] 어드민 검색 (패널명/기업명) — 디바운스 없음
  위치: src/pages/admin/PanelManagement.jsx, src/pages/admin/CompanyManagement.jsx
  현재: useMemo 클라이언트 필터에 디바운스 없음 → 키 입력마다 즉시 리렌더.

[M-4] panelTier — 구버전 tier 컬럼 사용으로 미션 정렬 신뢰도 저하
  위치: src/pages/panel/Missions.jsx
  현재: p.tier || 'ROOKIE' 로 isHighTier(미션 정렬 우선순위) 결정.

  기대: isHighTier 조건을 getHonorLevel(p.honor_points) 기반으로 교체

[M-6] 이미지 어노테이션 — 드래프트 복원 시 이미지 탭 방문 기록 초기화
  위치: src/pages/panel/ActiveMission.jsx
  재현: 이미지 3장 미션 → 2·3번 이미지 방문 → 임시저장 후 "이어하기" 재진입
  현재: viewedImages = new Set([0]) 로 항상 0번만 방문한 상태로 초기화 → 제출 불가.
  기대: 드래프트 복원 시 viewedImages를 전체 이미지 방문 완료로 초기화
