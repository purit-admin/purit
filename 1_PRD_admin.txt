## 미션 관리 (/admin/missions) — Missions.jsx
================================================================

- 의뢰명 검색: 260px 입력창 + ✕ 초기화
- 탭 4개: 전체 / 진행 / 완료 / 취소 (기본: 진행)
- 전체/메인/서브 전환 탭(missionKind, 기본 '전체' — '전체'는 항목 있는 섹션만, 개별 선택 시 해당 종류만), 5개씩 페이지네이션
- 딥링크: location.state.missionId 또는 ?missionId= → 자동 탭 전환 + 하이라이트 3초
- draft 미션 제외 (.neq('status', 'draft'))
- 유형 뱃지: 소재 비교 / 가격 검증 / 이메일 검증 (LP 검증 뱃지 미표시)

MissionCard:
- 상단: 뱃지·제목·기업명 + 슬롯 카운트 "N/N 패널 슬롯" + 버튼 그룹
- 하단: 등록일(좌) + 크레딧 현황(우)
  · 크레딧: "예상 N / 사용 N (환불 N cr)"
  · ↺ 재계산: recalc_mission_consumed RPC
- 카드 클릭 → 인라인 MissionDetail 펼침 (재클릭 닫힘)

MissionDetail (인라인):
- ※ 구 '미션 정보 Card'(제목·회사·슬롯·careerLevels)는 제거 — 바로 위 선택된 미션 카드와 전부 중복이라 들어냄(피드백 목록 Card만 유지)
- 피드백 목록 Card: 탭 5개 — 전체/작성중/검토중/승인/반려
  · 전체 탭 정렬: 승인 → 반려 → 검토중 (draft 미포함)
  · 작성중: status='draft' + submission_deadline 미만료만
  · 탭별 5개 페이지네이션
  · 피드백 행 클릭 → /admin/purity 딥링크

완료 처리 블락 조건:
```
completeBlocked = allFbs.length === 0 || reviewing.length > 0
```
- allFbs: status !== 'draft'
- reviewing: purity_passed=false && status!=='rejected' (검토 중)
