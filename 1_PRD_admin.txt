## 패널 관리 (/admin/panels) — PanelManagement.jsx
================================================================

- 통계 카드 4개: 전체 / 활성 / ⚠️ 위험(>0 빨강) / ⭐ 우수(>0 초록)
- 위험/우수 기준 (getFlag):
  · ⚠️: trust_score < 40 OR (기간 내 제출 ≥3 AND 반려율 > 50%)
  · ⭐: trust_score ≥ 80 AND 기간 내 제출 ≥3 AND 통과율 ≥ 80%
- 필터 바: 패널명 검색 / 상태(활성/심사대기/정지) / 기간 / 분류(위험/우수) / 레벨 / 정렬
  · ★ 정렬 기본값 = "최근 가입순"(joined_desc, created_at DESC) — 신규 가입 패널 최상단 (2026-06-12)
  · ★ "심사대기" 필터 버튼에 현재 심사대기 총 건수 빨간 뱃지 표시 (pendingCount, FilterGroup badges prop)
- ★ 신규 가입(미확인) 심사대기 패널 알림 뱃지 (2026-06-12):
  · 사이드바 "패널 관리" 메뉴에 빨간 뱃지 — "마지막 방문 이후 가입한 심사대기 패널 수"
  · localStorage(`purit_admin_panels_seen_${userId}`)에 마지막 방문 시각 저장 → created_at > 그 시각인 pending 수 카운트
  · /admin/panels 방문 시 시각 갱신 → 뱃지 0 초기화 / panels 테이블 Realtime 구독으로 신규 가입 시 자동 증가
- 테이블: ⚠️/⭐, 이름, 직군/경력, Trust, 레벨, 기간 제출, 통과율, 최근활동, 상태
- 테이블 행 클릭 → 우측 PanelDetail 패널 토글

PanelDetail (우측 360px):
- 기본 정보 Card: 이름 + 레벨 뱃지, Trust 게이지, 완료미션/가입일/최근활동/상태
  · isTempSuspend 시 황색 배너: "정지 해제 예정 N월 N일 HH:MM"
  · 계정 상태: active=✅ / pending=⏳ / suspended+suspend_until=🕐 임시 정지 / suspended+null=🚫 영구 정지
- 활동 통계 Card: 기간 내 제출/통과/반려 + PURITY PASS RATE 바
- 검증 서류 Card: health_insurance_url(createSignedUrl) / LinkedIn URL / 포트폴리오(signed URL or 외부링크)
- 제출 내역 Card: 전체 이력 5개씩 페이지네이션, 행 클릭 → /admin/purity 딥링크
- ★ 경력 확정 Card (2026-06-12) — PanelDetail에 key={panel.id}로 패널 전환 시 입력 초기화:
  · 현재 적용 경력 표시: is_executive → "C레벨/임원진" / experience_years → "N년차" / 확정일 + ✓확정됨 or 미확정(amber)
  · 연차 number input(상·하향) + "C레벨/임원" 체크박스(체크 시 연차 입력 disabled)
  · "경력 확정"(미확정) / "경력 재확정·조정"(확정됨) 버튼 → admin_confirm_panel_experience RPC (app_metadata role 검증)
  · 성공 시 부모 panels state 머지 + experience 텍스트 동기화('임원' or 'N년') → 보상 배율 즉시 반영
  · 안내: 확정 시점 기준 매년 자동 +1 (auto_increment_panel_experience pg_cron), 수동 상/하향 가능
  · 증빙은 위 "검증 서류 Card"의 건강보험 자격득실 확인서 링크로 확인
- 관리 액션 Card:
  · pending: 심사 승인(→active) / 심사 거절(→suspended)
  · active: 기간제 정지 2×2 그리드(1일·3일·7일·30일) + 영구 정지 → ConfirmModal(danger)
    - 기간제: panels.suspend_until = now+N일, pg_cron 매시간 만료 자동 해제
  · suspended: "정지 해제" (→active, suspend_until=null)
  · 모든 정지 액션 후 sendNotification 패널 알림:
    - 심사 거절 / 기간제 정지 / 영구 정지 / 정지 해제 → 각각 알림 발송
    - ★ 심사 거절·영구 정지 알림 문구: 문의 안내를 "고객센터" → "버그/불편 신고에서 문의" 로 변경 (2026-06-12)
- PAGE_SIZE: 10

## 미션 관리 (/admin/missions) — Missions.jsx
================================================================

- 의뢰명 검색: 260px 입력창 + ✕ 초기화
- 탭 4개: 전체 / 진행 / 완료 / 취소 (기본: 진행)
- 메인/서브 섹션 분리, 5개씩 페이지네이션
- 딥링크: location.state.missionId 또는 ?missionId= → 자동 탭 전환 + 하이라이트 3초
- draft 미션 제외 (.neq('status', 'draft'))
- 유형 뱃지: 소재 비교 / 가격 검증 / 이메일 검증 (LP 검증 뱃지 미표시)

MissionCard:
- 상단: 뱃지·제목·기업명 + 슬롯 카운트 "N/N 패널 슬롯" + 버튼 그룹
- 하단: 등록일(좌) + 크레딧 현황(우)
  · 크레딧: "예상 N / 사용 N (환불 N cr)"
  · ↺ 재계산: recalc_mission_consumed RPC
- 카드 클릭 → 인라인 MissionDetail 펼침 (재클릭 닫힘)

MissionDetail (인라인):
- 미션 정보 Card: 슬롯(allFbs+drafts/panel_count), 작성중 N명, careerLevels 뱃지
- 피드백 목록 Card: 탭 5개 — 전체/작성중/검토중/승인/반려
  · 전체 탭 정렬: 승인 → 반려 → 검토중 (draft 미포함)
  · 작성중: status='draft' + submission_deadline 미만료만
  · 탭별 5개 페이지네이션
  · 피드백 행 클릭 → /admin/purity 딥링크

완료 처리 블락 조건:
```
completeBlocked = allFbs.length === 0 || reviewing.length > 0
```
- allFbs: status !== 'draft'
- reviewing: purity_passed=false && status!=='rejected' (검토 중)
- 피드백 0건 → 버튼 미표시 (진행 탭만)
- 승인 0건 → 버튼 비활성 + "승인된 피드백이 없습니다"
- 검토 중 존재 → 비활성 + "검토 중 N건 먼저 처리 필요"
- 작성 중 존재 → 비활성 + "작성 중 N건 완료 대기"

완료 처리: ConfirmModal → complete_mission_and_refund RPC + 기업 완료 알림

조기 종료 완료 처리 (취소 탭):
- 조건: allFbs.length > 0 && pendingFbs.length === 0 && !m.company_notified_at
- ConfirmModal → missions.company_notified_at = now() UPDATE + 기업 알림 발송
- 완료 후: "기업 공개됨" 초록 Badge

완료 탭 '재진행': reactivate_mission_and_reclaim RPC (환불 크레딧 회수)
취소 탭 '재개': updateStatus('active') (크레딧 처리 없음)
취소 탭 '영구 삭제': ConfirmModal → missions DELETE

## Purity Filter (/admin/purity) — PurityFilter.jsx
================================================================

- 피드백 목록 정렬: 오래된 순 (ascending)
- 의뢰명 검색: 200px 입력창 + ✕ 초기화
- 상태 탭: 검토 대기 / 승인됨 / 반려됨
- 미션 타입 필터: 전체 / 메인 / 서브 (건수 실시간 표시)
- 딥링크: location.state.feedbackId → 자동 탭 전환 + 하이라이트 3초
- 서브 미션 점수 사전 로드(subResponseMap): preference/pricing/email 응답 테이블 일괄 조회

점수 공식:
- calcPurityScore (LP 메인): base20 + 길이(max20) + 섹션균형(max10) + 구체성키워드(×4,max25) + 실행가능성(×5,max25) + AI패널티(×-12,min-30)
- calcSubPurityScore (서브): base15 + 코멘트길이(max45) + 구체성키워드(×4,max20) + 지표충실도(max20)
- 65점 기준: 승인권장(≥65 초록) / 검토(45~64 네이비) / 반려권장(<45 빨강)

검토 대기 탭 65점 서브필터: 전체 / 65점 이상 / 65점 미만

일괄 처리 (검토 대기 탭):
- 체크박스 + "전체 선택" + 일괄 처리 바 (N개 선택됨 + 일괄 승인/반려/선택 해제)
- ConfirmModal로 사용자 승인 게이트 (D-88)
- 일괄 처리 후 recalc_mission_consumed RPC (미션별 그룹)

개별 승인:
- payout_amount 스냅샷: getPanelReward(panel.honor_points, panel.experience) → feedbacks.payout_amount
- rejection_penalty_applied=true 이었으면 +5 HP RPC (재승인 HP 복원)
- 알림: 패널 + 기업 양쪽 sendNotification

개별 반려:
- rejection_penalty_applied=true 저장
- rejection_deadline 설정 (메인 4h / 서브 2h from now)
- 반려 알림: 패널 actionUrl='/panel/history'
- decrement_mission_filled_count RPC (슬롯 반환)

승인 취소/반려 취소:
- ConfirmModal(danger) → reset(id)
- 반려 취소(isRejectReversal): restore_mission_slot RPC await → 실패 시 ConfirmModal errorMsg (D-65)
- confirmResetId + resetError state 패턴

피드백 상세 (좌측 선택 시 우측 표시):
- LP 미션: parseLPDesc → 미션 정보 카드(hasAnyInfo 조건) + ImageAnnotator + custom_answers
- 서브 미션: parseSubDesc 하위 호환 파싱
  · preference: variantA/B + 이미지 + customQuestions
  · pricing: 이미지 + content + customQuestions
  · email: content + customQuestions
- 점수 카드 컨테이너: CSS grid repeat(N, 1fr) (preference/pricing=3열, email/LP=5열)
